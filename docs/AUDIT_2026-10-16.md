# 匯率專案工程與量化稽核（2026-10-16）

## 結論

這是 USD/TWD 換匯監控專案。原系統的資料新鮮度、回測時序與模型可信度有實質缺陷；原有回測與信心百分比不足以支持「模型能幫忙省錢」。本次已修正可重現的程式問題、更新本機資料、重建特徵及重訓三個預測期間。尚未驗證或部署遠端正式服務，也沒有執行 LINE 發送。

修正後預設使用 `daily_v2` 特徵與 `phase4_ensemble_v2` 模型，保留舊資料及舊模型檔案供追查，避免混用修正前後的輸出。本機更新前備份位於 `data/audit_backup_20261016.db`（已由 gitignore 排除）。

## 已修正的問題

| 問題 | 影響 | 修正 |
| --- | --- | --- |
| 尚未成熟的未來報酬被比較成 False | 最後 1/5/20 筆被當成「不漲」，污染分類與回測 | 漲跌及尾端事件標籤保留缺失值，加入標籤到期日期 |
| 只按年份切訓練／測試 | 年底訓練標籤可能包含測試年的行情 | 所有實際模型驗證依標籤到期日排除交界樣本 |
| 前一年驗證權重包含尚未成熟標籤 | 新年權重可能利用當時未知的結果 | 權重只從當時已到期的驗證樣本計算 |
| 當日收盤訊號假設當日收盤成交 | 模型看到價格後仍被當成能按該價下單 | 模型訊號改用下一筆市場收盤價模擬成交，期限強制換匯仍是事前排定 |
| Yahoo 優先於央行收盤 | 官方收盤被補充來源覆蓋 | 同日期央行優先，Yahoo 作補充 |
| 當日未完成／未來日期的 Yahoo FX 日線 | 半成品價格混入已實現的標籤與指標 | 排除目前 UTC 日期及其後的 Yahoo FX 日線，排除所有未來日期 FX；重建時移除失效的未來特徵 |
| 跨市場只用日期合併 | 可能提前使用尚未公布的外國行情 | Yahoo／美債來源延後 1 日、FRED 延後 2 日的保守可用性代理，詳見下方限制 |
| 直接 reindex 遺失來源獨有交易日 | 台灣休市時海外新行情被跳過 | 先合併日期索引再向前填補，按原觀測日期檢查過期 |
| pandas 自動填值與外資缺失補零 | 資料中斷變成零報酬／零資金流 | 報酬不隱式填值，外資缺失保留為未知 |
| 缺失值 NaN 的真假判斷 | 未知訊號可能被算成極端風險，零完整度被改成 50% | 明確處理有限數值、零值及替代來源；完全無市場資料時完整度為零 |
| 以 recall 等混合分數分配機率模型權重 | 一直猜漲也可能獲得權重，差模型仍持續參與 | 以 Brier score 相對簡單基準的改善分配權重；未勝過基準的模型權重為零；移除 logistic 人為平衡類別權重 |
| 模型一致度被稱為信心 | 容易被解讀為經驗準確率或已校準機率 | 明確標註「資料與模型一致度（非準確率）」；歷史報酬分位數不再標示為條件預測的 80% 區間 |
| 資料正常就直接給選時建議 | 模型尚無真實追蹤驗證也會勸等待／換匯 | API、儀表板與 LINE 報告共用模型追蹤守門條件；缺乏驗證或追蹤偏弱時停用模型選時 |
| 過期預測與最新特徵混合 | 過去的機率套在今天價格 | 風險只使用與特徵日期一致的預測，品質檢查逐一核對三個期間 |
| 品質檢查未限制幣別／模型版本 | 其他貨幣或舊模型可能掩蓋缺失 | 限定 USD、USD/TWD、v2 特徵與 v2 模型 |
| 空資料、缺圖表欄位 | API 500／畫面例外 | 明確回應 503 或空資料訊息，圖表逐欄檢查 |
| API session 未關閉、反覆建立連線池 | 連線耗盡、延遲與額外 DDL | 快取有限數量的 engine／session factory，request 與畫面使用 context manager |
| GET overview 寫回預測風險 | 讀取頁面會修改歷史紀錄 | 風險快照計算改為唯讀 |
| webhook 驗證失敗仍回成功 | 無效請求也能進入事件處理 | 驗證失敗回 401，簽章通過後檢查 JSON／事件結構 |
| 無到期預測時監測程式崩潰 | 新模型上線後健康監測失敗 | 空樣本直接略過；7D/30D/90D 改按日曆時間篩選 |
| 排程用固定時間間隔當作依賴 | 抓取未完就建特徵，訓練未完就發送 | 22:30 UTC 啟動單一順序流程，失敗即停止後續步驟 |
| 畫面每次互動都重跑回測 | 畫面延遲、重複訓練 | 回測改由使用者按鈕觸發 |
| FRED 非 CSV 壓縮包錯誤處理 | 引用未匯入例外類別 | 正確拋出 ProviderError，增加回歸測試 |

## 本機實際重算

更新完成：15 個來源回報成功、0 個回報失敗；約 65,871 筆寫入／更新。成功指的是資料抓取流程完成，不代表每個來源完整、即時或銀行一定是華南。

v2 特徵共 2,645 筆，2016-08-17 至 2026-10-16。最新銀行來源仍為土地銀行備援，畫面與 API 已顯示銀行名稱、來源與時間；不能將它當成華南實際可成交報價。資料品質為 LIMITED，主要缺口為最新外資五日累計；缺失不再被補成零。

| --- | ---: | ---: | ---: | --- |
| 1 個觀測日 | 0.3120 | 0.2594 | 0.2593 | 簡單基準 100% |

| 20 個觀測日 | 0.3926 | 0.2966 | 0.2549 | 簡單基準 100% |

Brier 越低越好；固定給 50% 的參考分數為 0.25。連簡單基準的分數也未顯示足夠機率預測優勢，因此沒有理由把這些百分比稱為可靠機率或把模型複雜度當成價值。

2023 年起、每次 USD 10,000 的固定策略研究回測：模型選時平均成本比固定日期高約 NT$447，打敗固定日期的月份約 39%。最差匯率與成本波動有改善，但仍未通過平均成本條件。`should_use_for_timing=false`。修正後模型尚無到期的真實每日預測，追蹤狀態為 INSUFFICIENT_HISTORY；實際選時建議被守門條件停用。

## 尚未解決、不能宣稱已驗證的部分

- 跨市場延後 1／2 日只是保守代理，不是逐筆實際發布時間。FRED 最新 CSV 亦不是歷史 vintage 資料，仍可能有修訂偏誤；正式研究需要 ALFRED／其他 point-in-time 資料。現有回測不能宣稱已完全消除所有前視偏誤。
- 回測使用市場收盤價，沒有歷史華南即期賣出價、價差、手續費、可成交時間與真實付款日。月末需求仍為研究假設，尾端不完整月份及跨月視窗亦可能影響解讀；結果不能當作實際省錢證明。
- 尚未做獨立保留期、機率校準、重疊多日報酬的有效樣本數／信賴區間及多次策略搜尋的顯著性修正。通過成本指標也不會自動啟用實際選時。
- 真實家庭金額、付款日與台幣預算尚未配置；現有規則分數不是經驗違約或貶值機率。
- 正式服務是否持續更新尚未遠端核實。本機排程已改為有順序的流程，但多個 API worker／多個容器同時啟動 scheduler 的跨程序互斥仍需在部署設定或獨立 scheduler 服務處理。
- 過期資料門檻目前為七個日曆日，尚非逐來源交易日曆。需要更嚴格的新鮮度政策時，應按各市場假日及用途設定。
